# 交织者宣传片 v2 · 设计 spec 与分镜（制作放行文档）

> 流水线：video-shotcraft 自主自由创作。本文档 = 产品简报 + 需求决策 + 视觉方向 + 镜头映射 + 分镜表。
> v2 相对 v1 的变更驱动：① 开场→混剪的转场要丝滑（句号→点→圆→坍缩成三角形 + 运镜辅助）；
> ② 换真实 BGM 并全片卡点（强拍切点、高潮燃）；③ 修客观错误（圆-正弦联动的投影线必须是水平直线等）；
> ④ 高潮星图节点更扩散、贴近产品原作星图。

## 1. 产品简报

- **产品**：交织者 Interweaver —— 数学沙盒 Web App，"一张有数学灵魂的电子草稿纸"。
- **一句话**：GeoGebra 的能力 × 沙盒玩具的心流 × Minecraft 成就系统的驱动力，用"关联"一根线把数学知识缝成用户亲手织出的网。
- **不可妥协三原则**：原语极少组合无穷 / 画布即草稿纸 / 知识是一张网。
- **本片用途**：主旨+功能宣传片；受众：消遣型探索者 + 好奇的学生。
- **核心卖点（必须展示）**：绘制（点线圆/函数）、变量滑杆、**关联 Binding（正向 + 反向求解）**、约束、微积分工具组（割线/切线/导函数/积分）、**成就系统与知识网星图**。
- **硬约束**：1080p30、时长 2–3 分钟、全程左上角品牌 logo、中文文案、片尾 slogan「连一根线，看见整个世界。」、高潮落点「原来，知识是一张网。」、不直接使用用户提供的 logo/海报文件作为关键帧素材（logo 按其 SVG 路径数据代码重绘）。
- **数据口径**：知识网数据 = 产品真实 `achievements/nodes.js`（65 节点/89 边，提取自源码，已生成 `film/knowledgeData.js`）；无用户数据、无敏感信息。

## 2. 需求到执行决策表

| 用户反馈（v1） | 根因 | v2 决策 |
|---|---|---|
| 吐槽→混剪转场不自然 | v1 是"扫开"式 wipe，缺图形亲缘 | 改为**图形接力**：句号的点→离纸浮起→鼓成圆（实心镂空成环，circle-match-iris 命门写法）→圆坍缩成三角形→n→∞ 回到圆→圆即单位圆直接长出正弦。全程运镜配合（推近句号→跟点上升→随圆退开） |
| BGM 是程序合成，不燃、无卡点 | v1 音频全合成 | BGM 换 **Mixkit tech-house（约 124 BPM，强鼓点）**；librosa 网格拟合出真实 BPM/相位，**镜头边界全部 beatF 锚拍**；最强 kick 清单分给 3 处大 slam（成就砸落 / 星网心跳 / 终版落定） |
| 圆-正弦联动中间的线不是直的 | v1 Act1/Act3 里圆半径 r≠波振幅 amp（或圆心 y≠波基线），投影线斜 | 几何诚实规则写死：**凡投影参考线，圆的 r、波幅、圆心 y=波基线 三者必须相等**；Act3 欧拉装置改为 L 型布局（sin 向右、cos 向下，P 点的水平/竖直投影各自为直线） |
| 高潮星图不够震撼、点太挤 | v1 布局 1440×600 太密 | 星图扩散到 ~2400×1100（层距 340px、组带距 260px），镜头拉得更远再推回；节点保留产品的确定性微抖动 |
| （skill 判例预审）字幕字号 | v1 部分字幕 24–27px | Q11 硬线：叙事字幕 ≥56px、辅助 ≥32px，v2 全片按此重排 |
| （skill 判例预审）节奏偏快 | v1 平均每段停留偏短 | R1/R3：品牌字标 hold ≥1s、开场主体弧 ≥3s、每镜落定留呼吸 |

## 3. 视觉方向

**styleframe 跳过理由**：产品已有严格品牌规范（`docs/06-前端设计规范.md` + 品牌页 `app/brand/index.html` + 三张官方海报），v1 成片已验证该视觉在动态下成立；v2 沿用同一套 tokens，仅按上表修订。

- **双色体系**：纸面段 `#F5F5F7 / #1D1D1F / #5E5CE6`；深空段 `#0B0B12 / #8B86FF / #B9B6FF / #F5F3FF`；成就仪式金 `#C9A227 / #E3D68C`。
- **丝线**：产品连接视图同款（1.5px 行进虚线 `rgba(94,92,230,.5)` + 流动光点）——任何"联动"必须看得见那根线。
- **字体**：UI/标题 = PingFang SC → Microsoft YaHei 栈；数字/公式 = SF Mono → Consolas。
- **动效性格**：精致高端 × 平静关怀之间：主缓动 `bezier(0.32,0.72,0,1)`（iOS），落地类带轻微过冲 `spring`；招牌转场用 `bezier(.65,0,.35,1)` 平滑横移。
- **运镜**：默认稳定正视（Q3 无手持抖动）；推近/拉远以图形锚点为原点；全场冲击 ≤3 处（R4）。

## 6. 声音设计要点

- BGM：`bgm-tech-house.mp3`（Mixkit 免费商用，见 skill ATTRIBUTION），首尾 1s 淡入出；音量实测后给 SFX 留空。
- SFX：Freesound CC0 拟音——纸/打字（S0）、whoosh（转场运镜）、sparkle/水晶（连接与星亮）、相机快门（S4 三闪）、cinematic riser + impact + sparkle（S5 句式）、sub 心跳（S6）。
- 产品声音 DNA 保留一处叙事性使用：S5 成就弹出瞬间叠 `sfx.js achWeave` 三音（523.25/783.99/1046.5Hz，程序合成进 `public/audio/achWeave.wav`）——它是产品自己的成就音，属"系统提示音"的刻意叙事引用。
- 钉帧：中央 SFX 表全部 `beatF(n)` 派生；输出音轨偏移渲后交叉相关实测扣回（sound-design §4.6）。
