# 04 · 交互示例剧本

> 四个端到端剧本，把 02/03 章的机制串成用户真实经历的故事。每个剧本精确到"点哪里、拖什么、系统做什么、成就何时响"。评审产品是否"对味"，以剧本一、剧本四为准。

---

## 剧本一 · 正弦波与滑杆（需求原文场景的完整落地）

**用户目标**：无——只是打开网站，随手玩。

| 步 | 用户操作 | 系统行为 |
|----|---------|---------|
| 1 | 打开网站 | 空白草稿纸 + 淡网格。左上角三枚渐隐提示气泡：`画点什么` `拖一拖` `右键试试` |
| 2 | 点左侧「预设」图标 | 抽屉滑出，他选了**正弦波**，拖到画布中央 |
| 3 | 松手 | 正弦波落成，默认 A=1, λ=2π, φ=0，曲线是轮换色板的紫色。预设卡自动收起 |
| 4 | 好奇，拖了一下波峰 | 波形整体上下平移（系统判定：垂直拖动 → 反解到"中心 y"）；波随手而动，60fps |
| 5 | 右侧面板切到「变量」，点 `+` | 变量卡出现：`a = 0`。他输入 `9` |
| 6 | 右键正弦波 →「关联…」 | 面板列出参数表：`振幅 A` `波长 λ` `相位 φ` `中心` |
| 7 | 点「波长 λ」→ 来源选「变量 a」 | 一条光丝从变量卡飞到正弦波，λ 值跳变为 9，波形"唰"地展开。**首次关联完成，连接视图自动亮 3 秒** |
| 8 | 拖 `a` 的滑杆，从 9 拖到 2 | 正弦波实时压缩，像手风琴。滑杆拖动超过 1 秒 → 成就 **「波浪驯服者」**触发：波形发光脉冲 ×2，顶部弹卡 |
| 9 | 点变量卡上的 `▶` | a 在 [2, 12] 间自动往返，波呼吸起来。他看了十秒，截图 |

**本剧本验证的机制**：预设库 / 直接操纵反解 / 变量 / 两步关联器 / 前向求值 / 连接视图首教 / 成就 T3。

## 剧本二 · 拖直线，让波跟着动（反向求解）

**承接剧本一。**

| 步 | 用户操作 | 系统行为 |
|----|---------|---------|
| 1 | 按 `F`，输入 `2x+3=y` 回车 | 系统解析为 `y=2x+3`，画布上出现一条斜线（青色）。表达式无新字母，不弹滑杆建议 |
| 2 | 右键直线 →「关联…」→ 参数「角度」→ 来源「表达式」 | 输入 `a/9`，确认。直线角度被锁定到 `atan` 对应的值，丝线连上 `a` |
| 3 | 拖 `a` 的滑杆 | **直线旋转，同时正弦波伸缩**——两个实体被一根线驱动。他第一次直观看到"一个量控制两个世界" |
| 4 | 他直接抓住画布上的直线，拧它的角度 | 绑定 `angle ← a/9` 是线性可逆 → **解析反解**：`a = 9·angle`，变量卡的滑杆**自己动了起来**，正弦波同步变形 |
| 5 | 他把线拖到完全竖直（角度 90°）再松开 | a=…超出滑杆 max，滑杆短暂顶到端点并泛起弹性波纹（到达边界的温柔提示） |

**本剧本验证的机制**：函数生成器（任意语序）/ 表达式绑定 / 解析反解 / 反解沿计算图传播 / 边界 UX。

> ⚠️ 若绑定表达式不可逆（如 `angle ← a·sin(a)`），第 4 步将表现为"橡皮筋"：线被拉开、松手弹回，飘过提示。这是刻意的，见 02 章 §6.3。

## 剧本三 · 手搓微积分演示器（组合性证明）

**用户目标**：搞懂"导数到底是什么"。全程**不使用任何为"导数教学"定制的功能**，只用原语。

**目标装置**：拖一个滑杆 `h` 趋近 0，亲眼看割线"贴"成切线，斜率之差趋近 0。

| 步 | 操作 | 机制 |
|----|------|------|
| 1 | `F` → 输入 `y = sin(x)` | 函数实体 f₁ 生成 |
| 2 | 变量 `a = 1`；再建变量 `h = 1`（min 0.0001, max 2） | 两根滑杆 |
| 3 | 右键 f₁ →「曲线上取点」→ 点 P | P 的 `x` 参数绑定为 `a`（关联面板），P 落在 (1, sin1) |
| 4 | 再取点 Q，Q 的 `x` 绑定表达式 `a + h` | Q 落在 (1+h, sin(1+h)) |
| 5 | 选 P、Q → 右键「过两点直线」 | 割线生成，系统给出派生量 `slope`（差商） |
| 6 | 右键 P →「切线」 | 切线生成，其 `slope` = f′(1)（数值求导） |
| 7 | 右键割线 →「观察 slope」；切线同样 | 变量面板出现两块监视器：`m割 ≈ 1.04`，`m切 ≈ 0.54` |
| 8 | 再建观察器 `差 = m割 − m切` | 表达式引用两个观察器 |
| 9 | 按住 `h` 的滑杆，缓缓拖向 0 | Q 滑向 P，割线肉眼可见地旋转贴合切线；`差` 从 0.5 缩到 0.000… |
| 10 | `h` 进入 0.01 以下且 |差| < 0.01 | 成就 **「极限的一瞥」**触发：割线与切线交叠处发光，弹卡："你没算一个数，你看见了极限。" |

**再加三步成为 T4 大工程**：右键 f₁ →「生成导函数」（cos 曲线出现）→ 拖 `a` 滑杆，切线斜率监视器与 cos 曲线上 x=a 处的点同步起伏 → 右键 f₁ →「积分区域」，n 滑杆从 4 拖到 100，矩形密合成曲边梯形，S 收敛 → 成就 **「微积分的钥匙」**。

**这就是产品组合性的验收标准**：一个中学生用 10 个原语操作，搭出了市面上教学软件专门做一个页面的东西——而且是他自己的。

## 剧本四 · 欧拉之环（大工程 + 织网时刻）

**用户目标**：看到"正弦波是从圆里长出来的"。

| 步 | 操作 |
|----|------|
| 1 | 预设库拖入**单位圆**（自带动点 P(θ)，θ 为变量滑杆） |
| 2 | `F` → `y = sin(x)`；再生成 `y = cos(x)` |
| 3 | 在 sin 曲线上取点 S，S.x 绑定 `θ`；cos 曲线上取点 C，C.x 绑定 `θ` |
| 4 | P 到 S 拉一条**竖直参考线**（约束：竖直 + 过点 P 与 S 的水平对齐，用等长/对齐约束）；P 到 C 拉水平参考线 |
| 5 | 点 θ 滑杆的 `▶` 动画 | θ 匀速转动：P 绕圆旋转，S 在波上滑行，参考线像织布梭一样来回——圆与波同步呼吸 |
| 6 | 系统检测：圆 + sin + cos + 共享 θ + 绑定网闭合 → **「欧拉之环」**触发。这次的反馈是满级规格：全部相关实体依次发光，丝线脉冲汇聚成环，低音轰鸣 |
| 7 | 保存场景，命名《圆与波》 | 保存时提取知识指纹：{圆, 正弦, 余弦, 变量, 参考线(几何)} 间存在 5 组绑定耦合 |
| 8 | 他点开右上角徽章，第一次进入**成就页** | 镜头从他零零星星的几颗亮起节点拉升——新织的 5 条边**依次生长发光**，光脉冲沿边奔跑，最后他拥有的子网整体心跳一次。屏幕暗角浮出一行字：`圆 与 波，从此相连。` |

**这一分钟就是产品的全部意义。**

## 剧本五（反面） · 系统如何不挡路

| 情景 | 系统的"温柔" |
|------|------------|
| 用户输入了无法解析的表达式 `y = sin(` | 输入框下缘一行橙色小字实时提示缺括号，**不弹窗、不清空**，画布不变 |
| 用户绑定造成环：a → λ，又试图 λ → a | 第二步确认按钮置灰，按钮旁显示环路径示意 `a ⇄ λ`，附一句"这样会绕回自己哦" |
| 用户狂拖滑杆导致 500 个实体联动 | 拖动中自动降级非关联实体为低精度渲染，松手恢复——用户无感知 |
| 用户做了奇怪的"丑东西" | 什么都不发生。没有错误，没有评判。草稿纸不judge |
