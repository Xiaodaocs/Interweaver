# 07 · 风险、难点与竞品分析

> 本文档是对这个产品的**冷静审视**。前半回答"最大的问题是什么、难点在哪"，后半是竞品矩阵与差异化策略。写作立场：假设我们要拿真金白银投这个项目。

---

## 1. 最大的问题（按致命程度排序）

### ① 空白画布悖论：自由探索产品的留存死结 ★最致命

**问题**："完全自由"听起来性感，实则是留存毒药。打开一张白纸的用户，80% 会在 60 秒内陷入"我不知道该画什么"，然后流失。Minecraft 活下来的真正原因不是自由，而是**夜晚会来**（生存压力给了目标）；Euclidea 则直接给关卡。交织者目前的设计里，"目标"完全外包给了成就系统——但成就是**事后反馈**，不是**事前拉力**：它奖励已经探索的人，却无法告诉还没开始的人"往哪走"。

**证据级推演**：第一幕出口标准（剧本一 3 分钟上手）只验证"会玩"，验证不了"明天还想玩"。玩具型产品的第 2 日留存悬崖（行业典型 <20%）会在这里等着。

**缓解策略**（已写进路线图，但需承认这是赌注）：
- P16 的"引导模板 + 预织网拆解"是把"自由"伪装成"有起点"（打开即是一张织了一半的网："你能让它动起来吗？"）；
- P20 的"每周交织挑战"补目标拉力；
- 暗示系统（03 章 §7）在用户停滞时递台阶。
**如果这些都不奏效，退路是引入轻量"探索任务链"**（半开放目标：不给步骤，只给谜面，如"让圆里开出一朵花"）——这会牺牲一部分纯粹性，但可能救留存。

### ② 双向绑定的技术深度与心智成本 ★最难造

**问题**：用户要的核心魔法——"拖图形，变量跟着动；拖滑杆，图形跟着变"——在工程上是一个**带反解的响应式约束系统**。三层难点叠加：

1. **可逆性判定**：什么表达式能反解、在哪个定义域内单调可逆，需要对每个绑定做静态分析。`a/9` 可逆，`a·sin(a)` 在全域不可逆但局部可——这种"有时能拖有时弹回"的行为，用户能理解吗？
2. **一致性冲突**：绑定（有向）与约束（无向）共存时，"拖一个被两条约束夹住、又绑定了变量的点"，求解器该听谁的？优先级策略（硬约束 > 拖动 > 绑定）在边界情形会产生反直觉结果。
3. **心智模型泄漏**：用户需要隐约理解"因→果"的方向性才能玩得转，但我们的宗旨是"不教学"。连接视图是解法，但它本质上要求用户理解数据流图——这是给玩具用户看程序员的图。

**结论**：这是产品的技术护城河（做成了就是 Desmos/GeoGebra 都没完全做好的体验），也是最大工程量所在（P5+P7+P9 合计 13pw 且全部高风险标记）。**必须在 P7 出口用真实用户验证"反解是否可理解"，并保留降级形态**（只做正向滑杆驱动 + 拖动覆盖临时态）——降级后产品仍成立，但失去剧本二的神来之笔。

### ③ 成就语义识别：从"图形"到"知识"的鸿沟 ★最易翻车

**问题**："三条线段围成三角形"好识别；"用户在做极限"极难识别。剧本三中「极限的一瞥」要求系统理解：割线、切线、h 趋近 0、差值收敛——四个条件带数值容差地同时成立。风险有三：
- **误报**：用户随便拖拖就"达成"了微积分成就 → 成就贬值，核心用户失望；
- **漏报**：用户认真搭了但没被认出（因为用了预设而非手画，或容差没覆盖）→ 最伤：他做了对的事，世界没有回应；
- **组合爆炸**：60 个模式 × 1000 实体的子图匹配，性能和规则维护成本随成就库增长非线性上升。

**缓解**：容差 + 稳定确认 + 触发类型索引（已设计）；**上线前需要一轮"对抗性测试"**——请 10 个数学爱好者故意用奇怪方式构造同一知识，校准模式库。长期看，成就库运营（P20）是持续成本，不是一次性功能。

### ④ 定位撕裂：工具、玩具、课程的三体拉扯

GeoGebra 用户可以诘问"画精确图它不如 GG"，游戏玩家可以诘问"没关卡没目标不如玩真的游戏"，家长可以诘问"提分吗"。三个方向都有一头更专业的巨兽。**回答只能是**：我们三者都不是，我们卖的是"数学心流"这种情绪价值——但这个品类**尚无被验证的成功先例**（最接近的 PolyPad 是免费的教具公益项目，恰恰说明商业化未验证）。这是投资视角下真正的"最大的问题"：**一个好产品 ≠ 一个被验证的品类**。

### ⑤ 其余显著风险（简列）

| 风险 | 说明 | 缓解 |
|------|------|------|
| 性能长尾 | 用户会做出开发者想不到的巨型场景（500 绑定联动） | P17 渲染升级 + 降级策略 |
| 序列化兼容 | 场景 JSON 是长期负债，schema 演进必须向前兼容，否则老作品打不开=背叛用户 | P11 定迁移策略，写入工程纪律 |
| 内容冷启动 | 成就库/预设库上线初期单薄 | 60 成就+20 预设已是一期底线；赛季制续命 |
| 移动端 | 右键/悬停依赖在触屏失效 | P19 手势体系，iPad 优先 |
| 抄袭 | 交互创新易被大厂借鉴 | 护城河在成就语义库+社区作品，不在渲染技术 |

## 2. 技术难点排序（给研发的诚实清单）

1. **反向求解引擎**（P7）：可逆性分析 + 数值稳定 + 与约束求解器协同。业界可参考实现极少（CAD 的参数化求解器是最接近的，但那是工程师 UX，我们要做的是玩具手感）。
2. **几何约束求解器**（P9）：相切/过点等非线性约束的牛顿法收敛性、欠定/过定的优雅降级。kiwi.js 不够用的概率 >50%，预留自研预算。
3. **成就模式匹配引擎**（P12）：容差体系 + 增量匹配 + 规则可维护性。
4. **连接视图渲染**（P5/P14）：大量动态曲线的避障布局与流光效果，60fps。
5. **表达式生态**（P6）：隐函数 marching squares 的数值鲁棒性（尖点、断裂）。
6. **无限画布基础**（P1）：坐标精度（大平移下 float 抖动）、命中测试性能。—— 最成熟，风险最低。

## 3. 竞品分析

> 注：本分析基于撰写时的既有公开认知；搜索工具暂不可用，建议立项后用 SimilarWeb/财报数据复核各产品最新规模。

### 3.1 直接相关（数学交互工具）

| 竞品 | 它是什么 | 强 | 弱（我们的机会） |
|------|---------|-----|------------------|
| **GeoGebra** | 动态几何+代数教学套件，教育市场事实标准 | 功能是超集：约束、CAS、3D、课件生态、教师社区 | 界面为备课而生（工具墙）；零游戏化；无成就无情感；学生打开它是因为"老师让" |
| **Desmos** | 表达式驱动的图形计算器 | 表达式 UX 极致（自动滑杆建议被我们借鉴）；API 生态 | 不能自由绘图（无直尺圆规手感）；几何弱；纯工具无探索驱动；无双向反解 |
| **Mathigon Polypad** | "数学教具盒"，最接近电子草稿纸理念 | 自由摆积木的理念、设计精美 | 积木是**静态**的：没有绑定引擎、没有变量联动、没有约束求解——摆得出圆和波，但它们不会一起动 |
| **Euclidea** | 几何构造解谜游戏 | 游戏化验证成功（关卡驱动） | 有标准答案=封闭；仅限尺规几何；玩完即止 |
| **Brilliant / 可汗** | 交互课程 | 内容体系化 | 用户是乘客；无创作；与"遨游"相反 |
| **Wolfram Alpha/Mathematica** | 符号计算 | 计算深度 | 程序员心智，与玩具无关 |

### 3.2 间接相关（心流/沙盒品类参照）

- **Minecraft**：证明了"自由+目标系统（夜晚/成就/终末龙）"的留存公式——成就与引导不是附属品，是自由的地基。我们的 ① 号风险正源于此。
- **Zachtronics / Factorio**：证明"用简单原语组合出复杂机器"的核心循环有忠实付费人群；它们的"优化欲"对应我们的"交织欲"。
- **manim (3Blue1Brown)**：证明数学可视化的巨大受众，但它是视频工具（产出是观看），交织者把"做出 3B1B 同款画面"的能力交到用户手上——这是极具传播力的定位话术。
- **Excalidraw/tldraw**：草稿纸 UX 的标杆，但零数学语义。它们证明"画布手感"本身可以是产品壁垒。

### 3.3 差异化结论

```
            自由探索度
                ▲
   Polypad ●    │    ★ 交织者（目标位置）
                │      （自由 × 联动 × 游戏化反馈）
   Excalidraw ● │
  ──────────────┼──────────────▶ 数学语义深度
   Euclidea  ●  │  ● GeoGebra
                │     ● Desmos
```

**唯一的空位**：右上象限——同时拥有"数学语义深度"与"自由探索+游戏化"。GeoGebra 往左走（加游戏化）很难（它的用户是学校采购，不需要）；Euclidea 往右走很难（重构为开放沙盒等于重做）。**窗口真实存在，但空位存在的原因也可能恰恰是"这个交叉点没有市场"**——P1–P6 的最小闭环 + 第三幕成就系统内测，就是用最低成本回答这个问题。

### 3.4 如果被问"GeoGebra 抄你怎么办"

GeoGebra 的能力超集意味着它能做出我们的**功能**，但它的产品定位（学校采购的教学工具）决定了它做不了我们的**体验**：克制到 8 个图标的 UI、以心流为中心的交互、成就与知识网。真正的护城河是：① 成就语义模式库的长期运营积累；② 用户作品与"知识指纹"数据（谁的网上有什么，是我们独有的资产）；③ 品牌占据"数学沙盒玩具"心智。这些都与技术无关，与**持续运营**有关。

## 4. 给决策者的三句话

1. **值得做**：原语组合设计在纸面上是自洽的（剧本三证明了表达力），市场右上象限确实空着，技术难点都在"难而可行"区间而非"不可行"。
2. **最大的赌注不是技术，是留存**：空白画布悖论（§1-①）必须在第三幕内测时用数据回答；若 7 日留存 <15%，果断引入轻任务链，不要殉道于纯粹性。
3. **最小可信验证 = P1–P6 + 提前做一个粗糙成就原型**：不要等 P13 才验证情感假设——在 P6 的魔法时刻 demo 里手工埋 3 个成就（硬编码检测），找 20 个用户试玩，看他们点亮瞬间的表情。那 5 秒钟决定这个项目值不值得投两年。
