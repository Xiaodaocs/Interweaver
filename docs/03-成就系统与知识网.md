# 03 · 成就系统与知识网设计

> 成就系统是交织者的"灵魂器官"：它把用户无意识的操作翻译成"你发现了什么知识"，并用一张不断生长的网，让用户亲眼看见**知识是相互关联的**。
>
> 本章覆盖：检测引擎（怎么识别）、成就定义（识别什么）、反馈（怎么让人起鸡皮疙瘩）、知识网（怎么呈现"网"）。

## 1. 设计原则

1. **成就奖励"发现"，不奖励"劳动"。** 没有"画 100 条线"这种成就；只有"你构造出了一个从未见过的结构"。
2. **检测基于语义，不基于步骤。** 用户怎么画出三角形无所谓（三条线段围合 / 多边形工具 / 两点一圆规），系统识别的是**结果的结构**，而不是操作序列——这保护了草稿纸的自由。
3. **点亮靠独行，连线靠交织。** 单个知识点被构造出来 = 节点点亮；**多个知识点在同一个场景里通过绑定/约束协同工作** = 节点间连线亮起。孤立点亮的节点只是星，织起来的才是网。
4. **惊喜优先于图鉴。** 成就触发前不在 UI 里陈列清单（不剧透"还有哪些未发现"）；成就页默认只显示已点亮部分，未点亮区域以雾中暗星暗示"那里还有东西"。

## 2. 成就检测引擎

### 2.1 输入：场景语义图

渲染场景图在每次有效变更后（防抖 300ms）被编译为**语义图（Semantic Graph）**：

```
SNode = 实体（类型 + 关键参数特征，如"半径≈边长"、"角度≈60°"）
SEdge = 关系（重合 / 过点 / 约束类型 / 绑定路径 / 变量共享）
```

数值比较一律带容差（相对误差 ≤ 1%，角度 ≤ 0.5°），因为草稿纸上没有精确。

### 2.2 匹配：声明式模式库

每个成就 = 一条**声明式模式（Pattern）**，引擎做的是子图匹配 + 数值谓词：

```yaml
# 示例：「三角形诞生」
- id: geometry.triangle.born
  title: 第一块基石
  flavor: 三条线，一个世界。欧几里得从这里开始。
  tier: spark                       # 火种级
  match:
    nodes:
      - { type: Segment, as: s1 }
      - { type: Segment, as: s2 }
      - { type: Segment, as: s3 }
    edges:
      - { kind: coincident, between: [s1.end, s2.start] }
      - { kind: coincident, between: [s2.end, s3.start] }
      - { kind: coincident, between: [s3.end, s1.start] }
    where: "abs(s1.angle) 与 s2、s3 两两不共线"   # 排除退化

# 示例：「欧拉之环」（交织级大工程）
- id: weave.euler.ring
  title: 欧拉之环
  flavor: 圆在转动，波在生长——原来它们是同一件事。
  tier: weave
  match:
    nodes:
      - { type: Circle, as: c, where: "c.r ≈ 1 或任意" }
      - { type: Function, as: fsin, where: "fsin.expr ≡ sin" }
      - { type: Function, as: fcos, where: "fcos.expr ≡ cos" }
      - { type: Variable, as: θ }
    edges:
      - { kind: binding-path, from: θ, to: "c 上的动点 P.x 或 P.y" }
      - { kind: binding-path, from: θ, to: fsin.* }
      - { kind: binding-path, from: θ, to: fcos.* }
```

### 2.3 引擎实现要点

- **增量匹配**：不是每次全图跑所有模式。为每个模式维护"触发类型索引"（如"新增重合约束"只会唤醒含 coincident 的模式），变更事件驱动。
- **性能**：一期成就库 ~60 个模式，场景 ≤1000 实体时单次匹配 <10ms，完全可放在 idle callback。
- **防误报三件套**：数值容差 + 持续确认（结构需稳定存在 ≥500ms，防止拖动途中误触发）+ 每成就每场景只触发一次。
- **可扩展**：模式库是数据（YAML/JSON），发版即可新增成就，无需改引擎——为运营"成就赛季"留路。

## 3. 成就分级体系

| 级别 | 名称 | 含义 | 例子 | 一期数量 |
|------|------|------|------|---------|
| T1 | **火种 Spark** | 单个知识点的构造 | 三角形诞生、圆、第一根函数曲线、第一个变量 | ~24 |
| T2 | **结构 Structure** | 用约束/组合得到的几何或代数结构 | 直角三角形（勾股）、内切圆、抛物线的焦点性质 | ~18 |
| T3 | **交织 Weave** | 跨知识点用绑定/变量协同 | 滑杆驱动的正弦波、割线逼近切线（h→0）、欧拉之环 | ~14 |
| T4 | **巨匠 Masterwork** | 多系统复合的大工程 | 手搓微积分演示器、傅里叶方波合成、复平面上的旋转乘法 | ~6 |

## 4. 触发反馈（"冒光 + 弹窗"的规格）

时刻拆解（总时长 ~4s，可跳过，不可打断操作）：

| 时刻 | 画面 | 目的 |
|------|------|------|
| 0ms | 新诞生的关键形状**自内向外发光脉冲**（2 次呼吸，500ms，泛光 bloom），其余画面微降亮度 5% | 视线锚定："是它！" |
| 200ms | 成就卡从顶部**弹簧落入**（不遮挡画布中心）：磨砂玻璃卡，左侧成就徽章（金属质感符号，如 △ 内含一道弧光），右侧标题 + flavor 文案 | 命名顿悟："这叫三角形/这叫极限" |
| 800ms | 卡片下缘浮现一行小字：`✦ 已织入知识网 · 第 7 颗星` | 引导去成就页 |
| 3400ms | 卡片上滑收走，画布恢复；若 60s 内连续触发多个（探索高峰期），第 2 个起降级为右下角小气泡队列 | 不惩罚心流 |

**音效**（可关）：两音高的水晶泛音（上行大三度），T3/T4 级附加一声极低的"空间轰鸣"（sub-bass swell），给大成就以重量感。

## 5. 连线规则（点亮 vs 连接）

用户需求原文的机制，形式化为：

### 5.1 点亮（Ignite）
成就首次触发 → 知识网对应节点永久点亮（账号/本地存档级）。

### 5.2 连接（Weave）
保存场景时（或实时防抖），系统提取该场景的**知识指纹**：本场景匹配到的全部成就节点集合 K，以及它们之间真实的耦合证据：

- **绑定耦合**：两个知识点对应的实体/变量间存在绑定路径（如 θ 同时驱动圆与 sin）；
- **约束耦合**：对应实体间存在几何约束链；
- **共享变量**：被同一个变量驱动。

每对存在耦合证据的 (u, v) → 知识网上边 `u—v` **累计强度 +1**；强度 ≥1 即亮起，强度增加使线更亮更实（最多 3 档）。

> 例：用户在 A 场景点亮了「正弦波」，在 B 场景点亮了「圆」——两个节点各自发光但**无线**。
> 某天他做出欧拉公式演示（θ 同时驱动圆上动点与 sin/cos 曲线）→ 保存瞬间，「圆—正弦」「圆—余弦」「变量—三角」三条边**同时亮起**，并且因为这是一次成型的交织，额外触发 T3 成就「欧拉之环」。
> **这就是"知识是一张网"的证据交付时刻。**

### 5.3 预设知识点

知识网不只有成就节点：网中还存在**暗节点**（未获成就的知识概念，如"复数""矩阵"），被亮边经过/环绕时会显形轮廓，暗示"这片海域还未探索"——天然的长期目标系统。

## 6. 知识网可视化（成就页）

**这是全产品视觉预算最高的页面，目标是"第一次进入的人屏住呼吸"。** 设计规范细节见 [06-前端设计规范 §8](./06-前端设计规范.md)，此处定义体验结构。

### 6.1 场景与构图

- **深空暗色**：近黑蓝紫底色（`#0B0B12`），星尘微粒缓速漂浮（WebGL 粒子 ~400 颗，视差三层）。
- **网即星座**：知识节点按学科分区漂浮（几何 / 代数 / 三角 / 微积分 / 数与结构），分区间由暗雾分隔；节点=发光宝石（已点亮）或灰蓝暗星（未点亮，仅剪影）。
- **连线**：已织边=流动的光丝（与画布连接视图同一视觉语言！）；未织但系统预置的"知识亲缘"（如极限→导数）= 极暗虚线，仅在 hover 相邻节点时显形。
- **入场编排**：首次进入时相机从很远拉远——先看到自己点亮的寥寥几颗星——然后镜头缓缓拉升、旋转，整张（含暗星的）巨网浮现，一行字浮现：`已有 1,204 个知识点在等你。你点亮了 7 个。` **孤独感 × 宏大感 = 探索欲。**

### 6.2 交互

- 拖动旋转 / 滚轮缩放 / hover 节点：相邻边与节点增亮，其余压暗；点击节点：右侧滑出磨砂详情卡——成就名、flavor、**首次点亮时刻的场景缩略图**（"你的那一刻"）、与它相连的知识、以及一个按钮：「回到那个场景」。
- 点击已织边：显示"这条线在哪些作品里被织过"（场景列表）。
- **交织回放**：完成一次多知识点大工程后首次进入成就页，触发编排动画——本次新亮的边从旧节点**逐条生长**到新节点，光脉冲沿线奔跑，最后整张已有点亮子网轻轻脉动一次，像心跳。
- 顶部极简统计：点亮数 / 已织连线数 / "网密度"（一个鼓励交织的指标：边数/点数）。

### 6.3 技术

- 布局：离线预计算力导向布局（知识亲缘为边权重）+ 手工调校学科分区坐标，运行时零布局计算。
- 渲染：WebGL（实例化节点 + 线条 batch + bloom 后处理），降级方案为 Canvas2D（无粒子与泛光）。
- 规模目标：一期 ~60 成就节点 + ~40 暗节点 + ~150 条亲缘暗线，轻松 60fps；为长期 1000+ 节点预留 LOD（远处合并为星团）。

## 7. 引导与防挫败

- **前三个成就必现**：首会话内，新手引导（三步骤提示气泡）保证用户必然做出「三角形诞生」「第一个变量」「第一次关联」——让反馈循环在 5 分钟内完成第一轮。
- **暗示而非攻略**：长时间未点亮新节点时，画布边缘偶尔飘过一行手写字："试试把圆和一个变量连起来？"（按用户已有行为个性化）。
- **永不显示完成度压迫**：不设"总进度 %"常驻 UI；网密度等统计只在成就页内。
