# 06 · 前端设计规范（Apple 风格）

> 一句话：**像一张安静的白纸，直到你织出东西的那一刻，它为你燃放烟花。**
> 平时的克制（Apple 式的留白、磨砂、细线）与成就时刻的绚烂（辉光、星海、光流）形成戏剧反差，这是交织者视觉的灵魂。

---

## 0. 实现现状对照（技术/功能口径）

> 视觉调性不变；以下几条**原稿与落地形态不同**，以本节为准。

| 主题 | 原稿 | **实现现状（依据）** |
|------|------|-------------------|
| 默认主题 | §2.1「主界面（浅色，默认）」 | 仍是**逐页**主题：非成就页默认浅色，**成就页在新账号下默认深色**（`theme.js` 的 `PAGE_DEFAULT_MODES = { starmap: 'dark' }`）。用户在「设置 → 个性化」里可以**每页单独**设深/浅/跟随系统（键 `interweaver[.u<id>].pagetheme.<页面id>`），新页面自动获得键 |
| 主题切换动效 | §6「面板/弹窗 350ms、微件 200ms」 | 主题切换实际是 **View Transition 真页面软边对角横扫**（左上→右下，深浅双向，跨页也播）；`prefers-reduced-motion` 不播；不支持 View Transition 的浏览器直接切 |
| 布局 | §3「左侧 48px 工具栏 + 右侧 320px 三页签（变量/属性/ƒx）」 | 现在是：**底部 dock 条**（左边单独一个预设库按钮 + 右边 8 个工具）、**属性面板**（右侧，无选中时缩回）、**变量/观察器窗口**（右下 `#varWin`）、**函数创作器**（左上 `#fxDock`）、**设置卡**（左下 `#setCard`）。窗口统一走 `windows.js` 的 `makeWindow()`（标题条拖动 + 最小化吸附边缘） |
| 图标数量 | §1「图标 ≤8」 | dock 里是 **8 个工具 + 1 个独立的预设库按钮**（`index.html` 的 `#dockBar` / `#toolbar`）；且**没有长按 flyout**，也**没有文本标注工具** |
| 成就卡 / 成就页配色 | §2.1「成就页（深色）」token 表 | 成就卡与星图已是**深色宇宙**（深玻璃底 + 金色发丝边 + 辉光），具体色值以 P15 系列文档与 `styles.css` 为准；卡片可拖动、位置持久化 |
| 成就页星尘 | §8「三层视差星尘（~400 粒子，0.2/0.5/1.0 深度速率）」 | **已删除**（用户要求"删掉『星空』的背景逻辑"）：成就页的星场逻辑与容器都没了，`styles.css` 里 `.bgStars` 规则成为**遗留死规则**（待清理）。工作台那份更早就已移除 |
| 成就页分区色 | §8「几何=金、代数=蓝、三角=紫、微积分=青、数与结构=粉」 | 实际分组是**四组**：点与绑定 / 角与旋转 / 构造与约束 / 微积分（`nodes.js` 的 `GROUPS`），四色带；横轴是难度层级 L0–L6（左易右难），纵轴是组带 |
| 成就节点形状 | §9「成就徽章：60px 拉丝银底 + 学科色珐琅」 | 实际是**三档几何形状**（圆 / 圆角方 / 六边形徽标）+ **14 个手写 SVG path 图标**（`achievementShapes.js`，零图片素材） |
| 连接视图 | §5 视觉规格 | ✅ 已实现（键为设置里的 `connView`，快捷键 `Tab`，可整体关闭快捷键） |

## 1. 设计原则

1. **内容即界面**。画布占屏幕 ≥85%；所有 Chrome（工具栏/面板）悬浮于画布之上、可收起、半透明——向 visionOS / iPadOS 的悬浮玻璃语汇看齐。
2. **图标 ≤8，文字 ≤2 行**。任何面板不做工具墙（反例：Office Ribbon）。同类收长按，高级收右键，其余不存在。
3. **一根线的视觉语言贯穿全产品**。画布上的绑定丝线、滑杆卡引出的连线、成就页的光丝，**共享同一套渲染风格**（粗细/发光/脉冲）——用户在任何界面看到"线"都知道：这是知识的连接。
4. **数字必须美**。数学产品的数字是主角之一：等宽、精确、有呼吸感。
5. **动效即因果**。值变化时，变化必须沿"线"流过去（光脉冲），让用户看见因果，而不只是结果。

## 2. 设计令牌（Design Tokens）

### 2.1 色彩

**主界面（浅色，默认）**

| Token | 值 | 用途 |
|-------|-----|------|
| `--paper` | `#F5F5F7` | 画布底色（Apple 标志性浅灰，非纯白——降低长时间注视疲劳） |
| `--ink` | `#1D1D1F` | 主文字 / 默认图形墨色 |
| `--ink-2` | `#6E6E73` | 次要文字 |
| `--accent` | `#5E5CE6` | 品牌"交织紫"（选中态、绑定丝线、主按钮） |
| `--accent-soft` | `#5E5CE622` | 选中填充光晕 |
| `--glass` | `#FFFFFFB8` | 磨砂面板底（配合 backdrop-blur） |
| `--hairline` | `#00000014` | 1px 分隔线 |
| `--warn` | `#FF9F0A` | 温柔提示（表达式未闭合等，永不用红色惩罚） |

**探索色板**（新建实体轮换，色盲安全校过）：`#0A84FF 蓝` `#5E5CE6 紫` `#30D5C8 青` `#30B0C7 靛` `#64D2FF 天` `#FF9F0A 橙` `#FF6482 粉` `#98989D 灰`

**成就页（深色）**

| Token | 值 | 用途 |
|-------|-----|------|
| `--void` | `#0B0B12` | 深空底色（近黑蓝紫） |
| `--star-lit` | `#F5F3FF` | 点亮节点核心 |
| `--star-dim` | `#3A3A4A` | 未点亮暗星 |
| `--thread` | `#8B86FF` | 已织光丝 |
| `--thread-dim` | `#2A2A3A` | 亲缘暗线 |

### 2.2 字体

```css
--font-ui:   -apple-system, "SF Pro Text", "PingFang SC", "Inter", "Segoe UI", sans-serif;
--font-num:  "SF Mono", ui-monospace, "JetBrains Mono", monospace;   /* 一切数值、表达式 */
--font-math: "STIX Two Math", "Times New Roman", serif;              /* flavor 文案中的数学符号 */
```

字阶（rem）：`12 注释 / 13 面板正文 / 15 默认 / 17 标题 / 28 成就卡标题 / 40 成就页大数字`。
数值一律 `--font-num` + `font-variant-numeric: tabular-nums`。

### 2.3 间距 / 圆角 / 阴影 / 材质

- 8pt 网格：`4 8 12 16 24 32 48`。
- 圆角：小件 `8`，卡片 `14`，浮层 `20`，滑杆/药丸 `999`。
- 阴影（悬浮玻璃）：`0 8px 28px rgba(0,0,0,0.12), 0 1px 3px rgba(0,0,0,0.06)`；**无投影的 UI 不允许出现在画布上**（平面元素会被误读为内容）。
- 材质：所有浮层 `background: var(--glass); backdrop-filter: blur(24px) saturate(180%);` + 1px 白色高光内描边（`inset 0 0 0 0.5px #FFFFFF66`），即 macOS 菜单质感。

## 4. 关键组件规格

### 4.1 滑杆卡（变量面板的核心单元）

```
┌─────────────────────────────┐
│ a            ⛓3  ▶  ⋮       │  ← 名称 / 绑定数 / 动画 / 更多
│ ──────●───────────  9.00    │  ← 滑杆（紫）+ 等宽数值（可直接键入）
└─────────────────────────────┘
```

- 拖动中数值实时滚动（60fps），驱动中的被绑定实体同帧响应；
- 该变量被某个绑定反向驱动时（剧本二步骤 4），滑杆拇指泛起轻微紫色呼吸，暗示"它正被别人牵动"；
- 只读观察器卡：紫色换灰色，无滑杆，数值大号——它是"仪表"。

### 4.2 两步关联器（右键「关联…」）

不做对话框，做**面板内嵌向导**：右侧面板变身为关联器（标题"把 ○正弦波 的什么连出去？"），第一步参数列表（行内当前值+状态图标），第二步来源三页签（变量/画布拾取/表达式）。每步 200ms 横向滑动转场。底部永远只有「取消」——确认在选中来源瞬间自动完成（减少一次点击）。

### 4.3 上下文菜单

macOS 右键菜单样式：磨砂、圆角 10、行高 28、图标 14px、快捷键右对齐灰字。最多两级，一级 ≤7 项。

### 4.4 成就卡（弹窗）

```
      ╭──────────────────────────────────╮
      │  ◇        波浪驯服者               │
      │ 徽章      你让第一个量开始呼吸。     │
      │ 60px     ✦ 已织入知识网 · 第 7 颗星 │
      ╰──────────────────────────────────╯
```

磨砂玻璃 + 徽章金属浮雕 + 标题 28rem 字阶 + flavor 一行。入场：自顶部 `y:-80 → 0` 弹簧（见 §6），停留 2.6s，上滑收走。T3/T4 徽章带扫光动画。

## 5. 连接视图视觉规格（画布上的"线"）

| 元素 | 规格 |
|------|------|
| 丝线 | 1.5px，`--accent` 60% 透明，贝塞尔避开实体包围盒，曲率随距离自适应 |
| 光脉冲 | 沿路径奔跑的 6px 光点（`#B9B6FF` 辉光），数值每变化一次发一颗，速度 ∝ 变化率——滑杆拖得快，光点连成流 |
| 源端 | 小圆点吸附在变量卡边缘/实体参数热区 |
| 目标端 | 箭头消融于实体边缘 |
| hover 聚焦 | 其余丝线降至 15% 透明 |
| 成环预演 | 红橙虚线 + 抖动 |

## 6. 动效规范

- **全局弹簧**：`cubic-bezier(0.32, 0.72, 0, 1)`（iOS 招牌曲线）；面板/弹窗 350ms，微件 200ms， flyout 250ms。
- **值变化**：数字滚动用 120ms 补间；图形变化**不补间**（直接响应输入，物理感）。
- **发光脉冲**（成就触发）：实体自内向外 2 次呼吸，bloom 半径 12→28px，500ms/次。
- **橡皮筋**（不可逆绑定被拖）：位移 = 指针位移 × 0.3 + 阻尼振荡回弹，丝线呈被拉伸的绷紧态。
- **Reduced Motion**：系统级检测，全部转为 100ms 淡入淡出，光脉冲降级为静态高亮。

---

## 7. 主界面暗色模式

跟随系统。画布深灰 `#161618`，网格线相应降明度，探索色板统一 +10% 亮度。**注意：暗色模式 ≠ 成就页深空**——前者是工作环境的夜版，后者是仪式空间，材质（星空/辉光/粒子）不进入工作区。

## 8. 成就页（知识网）视觉专项

> 目标情绪：**孤独 × 宏大 × 心跳**。参考体验坐标：Apple 发布会的 Keynote 转场 ×《Sky 光·遇》的星图 × 天文馆。

| 项 | 规格 |
|----|------|
| 空间 | `--void` 深空 + 三层视差星尘（~400 粒子，0.2/0.5/1.0 深度速率），极缓漂移 |
| 节点 | 点亮：核心 `#F5F3FF` 2px + 辉光 16px + 学科色外环；未点亮：`--star-dim` 剪影，无光 |
| 织边 | `--thread` 1.5px 流光（与画布连接视图同源）；强度三档 = 亮度/宽度/脉冲频率递增 |
| 亲缘暗线 | `--thread-dim` 0.5px 虚线，hover 邻域才显形 |
| 学科分区 | 几何=金、代数=蓝、三角=紫、微积分=青、数与结构=粉（图例常驻右下，8px 字） |
| 入场编排 | ① 黑场 → ② 用户已点亮的几颗星在黑暗中亮起（孤独）→ ③ 镜头 4s 拉升拉远，暗星与雾海浮现（宏大）→ ④ 底部浮字：`已有 1,204 个知识点在等你。你点亮了 7 个。` → ⑤ 字散为星尘，进入可交互态 |
| 织网回放 | 新边从旧节点生长（dash-offset 动画，1.2s/条，间隔 0.3s），光脉冲跑完全程，最终已有点亮子网同步脉动一次（亮度 ×1.4，600ms）——"心跳" |
| 详情卡 | 右侧滑出磨砂深卡：成就名 / flavor / **首次点亮的场景缩略图** / 相连知识 / 「回到那个场景」按钮 |
| 音效 | 环境：极低音量太空 pad；交互：节点 hover 水晶音（音高随学科分区递变） |

性能：节点/边实例化渲染 + bloom 后处理（半分辨率）；>800 节点开启星团 LOD；Canvas2D 降级版关闭粒子与泛光但**保留编排叙事**（情绪不可降级）。

## 9. 图标与插画

- 工具/面板图标：SF Symbols 风格，1.5px 线性、圆角端点、24px 网格；禁用面性填充图标。
- 成就徽章：独立金属浮雕风（60px，拉丝银底 + 学科色珐琅），与工具图标刻意拉开档次——**工具是铅笔，成就是勋章**。
- 空状态：无插画的极简文字（例：变量面板空态 `连一根线，从这里开始` + 一个呼吸的 `+`）。

## 10. 可用性与无障碍

- 全键盘：工具单字母快捷键；`Tab` 连接视图；方向键微移选中实体（`Shift` ×10）。
- 触屏：长按=右键；双指捏合缩放；滑杆拇指触控区 ≥44pt。
- 色盲：探索色板经 CVD 模拟校验；绑定状态除颜色外必有图标/线型区分。
- 文案语气：温柔、第二人称、零术语说教。禁语清单：错误、失败、非法、无效 → 替换为"还没连上 / 这样会绕回自己 / 差一点点"。
