> 状态：**已实施（✅ 全部落地，含原计划的 T1–T5；T6 未做）**。本文保留为设计与验收依据，末尾 §7 是逐条回填的实施结果。

---

## 1. 背景与目标

**用户要求**：支持隐函数 —— 即 `F(x, y) = 0` 形式的曲线，例如 `x² + y² = 1`（圆）、`y² = x³ − x`（椭圆曲线）、`sin(x·y) = 0.5`。

**现状缺口**：`func` 实体只支持单值函数 `y = f(x)`（沿 x 采样画折线），无法表达竖直切线、闭合曲线、多值曲线。

**成功判据（可机器断言）**：
1. 能创建隐函数实体并在画布渲染出正确曲线（用 `x²+y²=1` 必出**闭合圆**做像素级断言）；
2. 表达式引用的**变量 / 实体参数**变化时曲线**实时**更新（与既有联动语义一致）；
3. 单帧绘制 < 16ms（依赖缓存命中；全量重算走分片，不拖帧）；
4. 不破坏既有 `npm run verify` 全绿（含 134 条成就）。

## 3. 设计

### 3.1 实体模型：**新增 `implicit` 类型**（推荐，不扩展 func）

```
REGISTRY.implicit = {
  params: { expr: '…' },          // 统一存 F(x,y)，见 3.2
  几何/派生: 一期不参与派生（无 pointOnHost），避免波及切线/积分等派生实体
}
```

**为什么不用"func 表达式含 y 就算隐函数"**：func 的语义（y=f(x)）已被 134 条成就、T4 三档、语义图谓词依赖；隐函数混进去会让既有判据误判（同一 expr 有时单值有时多值）。新类型做**完全隔离**，成就与测试零风险。

### 3.2 双变量求值：`evalWith2(ast, x, y)`

- 在 `graph.js` 的 `evalWith` 旁新增 `evalWith2(ast, x, y)`：同样建立作用域，但多绑定一个 `y`（与 `x` 同级）。
- **统一存 F(x,y)**：用户输入支持 `=` 形式，**在向导输入层解析**：`左式 = 右式` → `F = 左式 − 右式`；无 `=` 则原样视为 F。
  - 例：`x^2+y^2=1` → `x^2+y^2-1`；`y^2=x^3-x` → `y^2-(x^3-x)`。
  - AST/求值层**不感知等号**，改动最小。

### 3.3 渲染算法：**marching squares（等值线提取）**

```
对可见世界矩形打网格（屏幕 ≈5px/格）
  每格四角求 F → 得 16 种符号模式之一
  对跨零边做线性插值 → 出等值线段
  相邻共线小段合并为 polyline（控制图元数）
```

**性能（关键，必须缓存 + 分片）**：
- 每帧全图求值约数万次 → **不可行**；必须缓存：
  - **缓存键** = 编译产物 + 全部引用变量/参数的值 + 可见世界矩形 + 网格步长；
  - **失效** = 任一依赖变化，或相机平移/缩放超过半格 → 重算；
  - **重算走分片**：`requestIdleCallback` 或按"每帧最多 N 毫秒"切片，期间显示上一帧曲线（绝不拖帧）。
- **远视角降采样**：缩得越小、格越粗（等值线在大视野下不需要细）。

**数值健壮性**：
- F 为 NaN/±∞ 的格跳过；
- 容差：|F| 小于相对阈值的格视为"在线上"，避免锯齿断裂；
- 竖直切线处 marching squares 可能断线 → 提高局部密度或接受（记入已知限制）。

### 3.4 UI 入口

- **fx 向导（函数创作器）加「隐函数」类型**：输入框提示「如 x^2+y^2=1 或 y^2-x^3+x」；有 `=` 时按 3.2 拆分。
- 渲染样式：沿用实体色板，默认 1.5px 描边。

### 3.5 交互（二期，可不做）

- 一期**纯显示**。
- 二期：点击曲线取点（在网格缓存上局部搜索最近零交叉）；**本方案不含**。

## 5. 风险与取舍（提前说明）

1. **性能**：网格求值是最大风险 → 缓存 + 分片 + 远视降采样；若仍超预算，可限制最大网格密度（视野越大越粗）。
2. **断线/锯齿**：竖直切线与稀疏网格处 marching squares 会断 → 已知限制，必要时局部加密。
3. **与既有系统隔离**：新类型 `implicit` 不进派生体系、不动 func 语义 → 134 条成就与既有 verify 不受影响（这是选新类型而非扩展 func 的核心原因）。
4. **多值/闭合曲线**正是隐函数的意义 → 不能用"转 y=f(x) 多支"取巧（竖直线 x=1 无法表示为多支函数）。
