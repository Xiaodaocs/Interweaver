## §3.2 密度与呼吸感（"该密的时候密，该散的时候能分清"）

### 问题（现状实测）
现在全图是**均匀的 46px 最小间距**（实测 `minGap = 46.0`），横竖都均匀 → **没有疏密对比**，
所以看起来"平"，也就没有"呼吸"。用户要的是：**同一簇内有意识地密，簇与簇之间明确地散**。

### 规划（四条量化规则）

| 规则 | 数值 | 目的 |
|---|---|---|
| **组内密** | 同组同列的节点间距 **46–64px** | 一簇知识点看起来"织在一起" |
| **组间散** | 相邻两条**组带之间的留白 ≥ 120px** | "能分清哪个是哪个"（不同组一眼分开） |
| **枢纽密** | 依赖度 ≥3 的节点与其邻居的弹簧长度 **140–200px**（原 180–260） | 圆心/变量这类"枢纽"自然收成一团 → 该密的地方密 |
| **叶端散** | 依赖度 =1 的节点弹簧 **240–320px** | 末端散开，读起来不挤 |

### 补充：跨层的"节奏留白"
跨 `k` 层的一条边，其两端所在层之间的走廊额外加宽：`走廊 = 56 + 14×(k−1)`。
效果：层与层之间不是等距切片，而是随难度跨度**有节奏地呼吸**。

### 验收（写进 `npm run verify`）
1. `minGap ≥ 46`（不放宽）
2. 组带之间留白 ≥ 120px
3. **疏密对比成立**：枢纽节点的平均邻居距离 / 叶端节点的平均邻居距离 **≤ 0.75**
4. 首屏（zoom 1.6）可见节点数 8–14（与 T5 联动）

## §3.3 防交叉 + 拱桥（两条同时用）

现状：每条边**独占一条车道**（实测共用车道 = 0 ✓）、交叉处画小拱桥（实测 57 处）。
用户要求"**防交叉**"与"**拱桥**"并用 —— 即：**先尽量不交叉，剩下的才用拱桥跨过去。**

### 规划（三步，按收益排序）

**P1 · 长边拆段（dummy 节点）—— 修正：交叉的根源是"长边"，不是"层内次序"**

> **实测推翻了我最初的 P1**（原方案写的是"层内 median 重排是降交叉主力"）：
> - 层的跨列跨度分布：跨1层 **21** 条 / 跨2层 11 / 跨3层 8 / 跨4层 **15** / 跨5层 7 / 跨6层 2
>   → **43/64 条边跨 ≥2 层，24 条跨 ≥4 层**；
> - 两次尝试均失败并已回退：车道单调分配 57 → **63**（且穿线 0 → 4 ✗）；层内 median 重排 57 → **90** ✗。
> - 原因：长边的水平段要**横穿 4–6 列**，途中必然与大量无关边的竖直段相交 ——
>   这与"层内节点谁高谁低"无关，所以重排/单调都无法改善它。

因此 P1 改为：**跨 ≥3 层的边拆成若干段**，每段在中间列引入一个"虚拟节点"（dummy），
虚拟节点参与与真实节点相同的车道分配与避让 → 长边被打散进各列空隙，交叉大幅下降。

**P2 · 主干道（highway）**
在每条组带的**上缘与下缘各留一条专用车道**（6px），跨 ≥4 层的边一律走主干道 →
长边的水平段只出现在带边缘，不再穿过密集区。

**P3 · 曲线回退（用户已允许："实在做不出来就使用曲线"）**
跨 ≥4 层且主干道已满的边改用三次贝塞尔；曲线与正交线相交处只画一个 2.2px 小圆点提示。

**P4 · 剩余短边交叉画拱桥（保留 Minecraft 风格）**，且拱桥数 = 交叉数。


### 验收
- `穿非端点节点 = 0`（已有，保持）
- **交叉数 ≤ 15**（先记录基线，再逐步收紧）
- 拱桥数 = 交叉数（一一对应，不许漏画）

## §3.4 曲线回退（"实在做不出来就使用曲线重新排列"）

### 触发条件（满足其一即改用曲线）
1. 正交走线的**弯数 ≥ 5**（正常 Z 形是 2 个弯）；
2. 绕行长度 > 两端直线距离 **× 1.8**；
3. 该边跨 ≥3 层，且中间列的车道**全部被占用**（无独占车道可分配）。

### 曲线规格
- **三次贝塞尔**：`P0 = 源节点端口`，`P1 = P0 + 切向×L`，`P2 = P3 − 切向×L`，`P3 = 目标端口`，
  切向取**水平出/入**（`±1, 0`），`L = clamp(|Δx|×0.35, 60, 160)`；
- **参与避让**：曲线的竖直控制偏移量在"该列空闲 y 区间"里选取（复用 §3 的空闲区间算法）；
- **不穿节点**：对曲线采样 24 点做矩形相交检测，要求 **0 命中**；
- **视觉**：与正交边同样醒目（颜色/发光一致），但**不画拱桥**（曲线上不适用），
  改为在曲线与其它线相交处画一个 **2.2px 的小圆点**作为"相交提示"；
- **上限**：曲线边占比 **≤ 25%**（否则说明布局本身需要重排，而不是让走线去将就）。

### 验收
- 所有曲线边：采样 24 点 **0 命中**任何非端点节点
- 曲线占比 ≤ 25%
- 出截图 `p15-t3-curves.png` 对比正交/曲线两种走法的观感
