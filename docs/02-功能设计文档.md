## 1. 系统总览：五个原语

交织者的全部功能由五个原语（Primitive）组合而成。**任何新功能提案，必须先证明它无法用这五个原语组合得到，否则不予加入。**

| 原语 | 一句话定义 | 类比 |
|------|-----------|------|
| **实体 Entity** | 画布上有数学语义的对象（点、线、圆、函数图像、向量……） | 乐高积木 |
| **参数 Parameter** | 每个实体暴露的数值端口（圆心 x/y、半径 r、角度 θ、波长 λ……） | 积木上的凸点 |
| **变量 Variable** | 用户创建的全局量，带滑杆，可被绑定也可绑定别人 | 电压源 / 旋钮 |
| **绑定 Binding** | `目标参数 ← 表达式(源)` 的有向连线，构成响应式计算图 | 电线 |
| **约束 Constraint** | 几何关系（重合、过点、垂直、相切、等长……），由求解器维持 | 榫卯 |

辅助设施：**观察器 Probe**（把任意量显示出来，本身也是变量）、**预设库**（打包好的实体组合）、**函数生成器**（表达式 → 实体）、**成就引擎**（监听场景图，识别知识模式）。

### 1.1 运行时架构（概念）

```
┌───────────────────────── 交互层 ─────────────────────────┐
│ 画布(指针/触控)  左侧工具栏  右侧面板  右键菜单  连接视图     │
└──────────┬───────────────────────────────┬─────────────┘
           │ 拖动/绘制                        │ 滑杆/输入
           ▼                                 ▼
┌──────────────────────────────────────────────────────────┐
│ 场景图 Scene Graph：所有实体、参数、变量、约束的单源事实     │
│  ┌────────────────┐        ┌──────────────────────────┐  │
│  │ 约束求解器       │───────▶│ 响应式计算图 (DAG)          │  │
│  │ (几何关系,软约束) │ 自由参数 │ 绑定表达式求值 + 反向求解   │  │
│  └────────────────┘        └───────────┬──────────────┘  │
└────────────────────────────────────────┼─────────────────┘
                                         ▼ 变更集
                              ┌─────────────────────┐
                              │ 渲染器 (Canvas2D→WebGL)│
                              └─────────────────────┘
                                         ▼ 场景变更事件
                              ┌─────────────────────┐
                              │ 成就检测引擎 (模式匹配) │──▶ 弹窗/发光/织网
                              └─────────────────────┘
```

**每帧数据流**（60fps 目标）：
1. 指针拖动 → 把被拖参数写入求解器为"软约束"（目标值=指针位置）。
2. 约束求解器解出所有自由几何参数。
3. 反向求解：被拖的**已绑定**参数尝试沿绑定表达式反解到上游变量（见 §6.3）。
4. 响应式图拓扑序前向求值。
5. 渲染增量重绘；场景变更事件送入成就引擎（防抖）。

## 2. 画布（电子草稿纸本体）

### 2.1 基础行为

| 能力 | 规格 |
|------|------|
| 无限画布 | 平移（空格+拖拽 / 双指）、缩放（滚轮 / 捏合，以指针为锚点），缩放范围 0.05×–50× |
| 坐标网格 | 默认显示笛卡尔网格，缩放自适应密度（1/2/5 进制），原点和坐标轴有轻微强调；可在设置中切换：网格/点阵/极坐标/纯净纸 |
| 吸附 | 拖动时软吸附：网格交点、已有实体特征点（端点/中点/圆心/交点）、水平/垂直角。吸附以"磁性"手感实现（进入半径内减速+轻跳），按住 `Alt` 临时关闭 |
| 撤销/重做 | `Ctrl+Z / Ctrl+Shift+Z`，完整历史栈（含绑定、变量操作），上限 500 步 |
| 选择 | 单击选中；框选多选；`Esc` 取消；选中态=苹果式蓝色描边光晕，不显示丑手柄 |
| 直接操纵 | **所有图形都可以直接拖**。拖圆的边缘改半径，拖圆心改位置；拖直线上一点改角度，拖直线本体改位置。每个可拖部位 hover 时有 2px 高亮提示 |
| 手绘平滑 | 自由画笔轨迹做 Ramer-Douglas 简化 + 贝塞尔拟合，保留手绘感但去除抖动 |

### 2.2 渲染表现

- 线条：2px 圆角线帽，抗锯齿；手绘风微扰动（可选"草稿纸纹理"主题，让线条像铅笔）。
- 颜色：默认墨色 `#1D1D1F`；新建实体自动从 8 色探索色板轮换（蓝/紫/青/绿/橙/粉/金/灰），用户可改。
- 交点：两实体相交处自动显示小圆点（可在设置关闭）， hover 显示坐标。
- 性能基线：1000 个实体 + 50 条绑定，拖动时保持 60fps（M 系芯片 MacBook / 中端手机 40fps+）。超出后降级策略：拖动中降低非关联实体渲染精度。

## 3. 实体类型与参数表

**设计规则：每个实体必须公开完整参数表；参数是绑定系统的"端口"。** 下表是一期实体集（标注 🧮 者为微积分工具组，见 §10）。

### 3.1 几何实体

| 实体 | 创建方式 | 公开参数（均可被绑定/绑定别人） |
|------|---------|-------------------------------|
| 点 Point | 点工具单击 | `x`, `y` |
| 线段 Segment | 直尺两点 | `x1,y1,x2,y2`（派生：`length`, `angle`） |
| 直线 Line | 直尺（长按切换） | 点向式：`px,py,angle`（派生：`slope`, `intercept`） |
| 射线 Ray | 直尺（长按切换） | `px,py,angle` |
| 圆 Circle | 圆规（圆心+半径） | `cx, cy, r`（派生：`area`, `circumference`） |
| 圆弧 Arc | 圆上取两点 | `cx, cy, r, startAngle, sweepAngle` |
| 多边形 Polygon | 连续点击闭合 | 顶点列表 `pts[]`（派生：`area`, `perimeter`）；正多边形为预设（`n`, `r`, `rotation`） |
| 角 Angle | 选两条线自动识别 / 角工具 | `vertex, θ` |
| 向量 Vector | 向量工具 | `px, py, dx, dy`（派生：`magnitude`, `direction`） |
| 自由曲线 Freehand | 画笔 | 采样点列（派生：`length`）；可升维为"拟合曲线"获得解析参数 |
| 圆锥曲线 Conic | 预设库拖入（椭圆/抛物线/双曲线） | `a, b/c, cx, cy, rotation`（派生：`e` 离心率, 焦点坐标） |

### 3.2 函数实体

| 实体 | 输入形式 | 公开参数 |
|------|---------|---------|
| 显函数 `y=f(x)` | 函数生成器输入 `y = 2x+3` / `y = sin(x)` | 表达式中出现的全部字母系数（`a,b,k…` 自动提取）；定义域 `[d1,d2]` |
| 隐函数 `F(x,y)=0` | 输入 `x²+y² = 25` | 同上；渲染为等高线 0 值线 |
| 参数曲线 | 输入 `x=cos(t), y=sin(2t)` | `t` 范围、系数字母 |
| 极坐标 | 输入 `r = θ` | 同上 |
| 导函数 🧮 | 右键某函数 →「生成导函数」 | 源函数引用；自身作为新函数实体参与一切绑定 |
| 积分区域 🧮 | 右键某函数 →「积分区域」 | `a, b`（区间端点，可拖）、`n`（分割数）、`method`（**左 / 右 / 中点 / 梯形**）；派生：`S` 近似值、`error`。**只对显函数型宿主生效**；隐函数与圆这类"一个 x 对多个 y"的宿主会被明确拒绝并说明原因 |

### 3.3 参数的统一性质

每个参数槽（Param Slot）有四种状态，在右侧面板用不同视觉表达：

| 状态 | 含义 | 视觉 | 可拖？ |
|------|------|------|--------|
| **自由** | 普通数值，直接编辑或拖动 | 白色数字 | ✅ |
| **绑定** | 由表达式驱动（单向） | 数字左侧有"线"图标，值实时流动 | 尝试拖动 → 触发反向求解（§6.3），不可解则轻微回弹 |
| **锁定** | 用户显式钉死 | 🔒 | ❌（先解锁） |
| **观测中** | 被观察器引用 | 数字右侧有眼睛图标 | 正常 |

## 5. 变量系统与滑杆面板

### 5.1 变量

- 右侧面板「变量」页，`+` 创建：名称、初值、范围 `[min, max]`、步长（可为 0 = 连续）。
- 变量名即全局符号，可用于任何绑定表达式与函数生成器（`y = a·x + b` 中的 `a`、`b` 若未定义，**自动建议"创建滑杆"**——一键生成，Desmos 同款体验）。
- 每个变量一条滑杆卡片：名称 / 当前值（可直接输入）/ 滑杆 / 三个小操作：`▶ 动画`（在 min↔max 间往返，速度可调）、`⛓ 绑定数`（hover 高亮所有被它驱动的实体）、`⋮ 更多`。

### 5.2 观察器（Probe）

- 右键任何实体 →「观察」→ 选派生量（如三角形 `area`、直线 `slope`）→ 在变量面板生成一条**只读显示器卡片**。
- 观察器是**一等变量**：可以被别的表达式引用（例：`c = area1 / 10` → 圆的半径绑定 `c`，于是"拖三角形，圆跟着变"）。
- 观察器 + 变量 + 绑定，构成完整的**双向信号流**。

### 5.3 示例（用户需求原文的落地）

> 画一个正弦波 → 创建变量 `a = 9` → 右键正弦波 → 关联 → 参数「波长 λ」← 来源「变量 a」。
> 此后拖动 `a` 的滑杆，正弦波实时伸缩。✅

## 6. 绑定引擎（全产品的技术核心）

### 6.1 绑定模型

一条绑定（Binding）：

```
Binding {
  id
  target:  ParamRef            // 实体.参数，如 sine1.wavelength
  expr:    ExpressionAST       // 表达式树，引用若干源
  sources: ParamRef[]          // 从 AST 静态分析得出
  inverse: InverseStrategy     // none | analytic(f⁻¹) | numeric(牛顿迭代)
}
```

- 表达式语言：四则、幂、三角、对数、`abs/min/max/clamp/lerp`、条件；引用语法 `实体名.参数`（如 `circle1.r`）、变量名、观察器名、常量 `π e`、内置时间 `t`。
- 所有绑定构成**有向图**。创建绑定时做环检测：成环则拒绝并给出人话提示（"这样连会绕回自己：a → λ → b → a"），并以红色虚线预演成环路径。

### 6.2 前向求值

- 依赖图拓扑排序，变更时仅重算受影响子图（脏标记）。
- 求值器为纯函数，每帧预算 <4ms（100 条绑定内绰绰有余）。

### 6.3 反向求解（Inverse Solving）——"拖图形，变量跟着动"

用户的核心期待（需求原文）：*拖动直线的角度 → 变量 a 变化 → 与 a 关联的正弦波也动。*

分三档处理：

| 档位 | 条件 | 行为 |
|------|------|------|
| **解析反解** | 表达式对某单源单调可逆（线性、`k·x`、`x²`(限域)、`sin(x)`(限域)…） | 拖动目标参数 → 计算 `source = f⁻¹(target)` → 写回上游变量 → 前向传播。**用户感觉就像直接在拖"现实"** |
| **数值反解** | 单源、连续但无解析逆 | 牛顿迭代 + 拖动起点初值，每帧 ≤ 8 次迭代；失败回退到"弹簧"档 |
| **弹簧回弹** | 多源 / 不单调 / 无解 | 图形跟随指针被"拉开"，松手弹回绑定值；拉开时绑定线以橡皮筋可视化，并飘过提示："`λ` 正由 `a` 驱动——拖 `a` 的滑杆试试" |

**反解传播链**：若上游变量本身也是另一个绑定的目标，则递归反解（深度限 8，全程保持 DAG 无环）。这是"拖直线 → 改变 a → 正弦波变形"的完整实现机制。

### 6.4 连接视图（Interweave View）——品牌隐喻的画布落地

- 底部居中开关（或快捷键 `Tab`）切换。开启后：
  - 画布上所有绑定画成**纤细的发光丝线**，从源参数连到目标参数，贝塞尔曲线避开实体；
  - 数值流动时丝线上有微光脉冲（shader 实现的流动点）；
  - 变量面板中的滑杆与画布实体之间也连线（面板边缘引出）；
  - hover 任一变量的 `⛓`，其余丝线变暗，只留它的子网。
- 这一视图同时是**调试工具**（用户理解"谁在驱动谁"）与**情感高光**（截图即海报）。默认在第一次创建绑定后自动短暂开启 3 秒，教会用户它的存在。

### 6.5 绑定编辑 UX

右键实体 →「关联…」进入两步选择器（不做复杂对话框，保持轻量）：

1. **选目标参数**：面板列出该实体参数表（λ / A / φ / 中心 x / 中心 y…），每行显示当前值与状态。
2. **选来源**：三个页签 — `变量`（已有滑杆+新建）/ `实体参数`（点选画布上另一实体 → 列出其参数）/ `表达式`（自由输入，实时预览计算值与曲线）。
3. 确认后丝线飞过画布连上二者（微动画），完成。

## 7. 约束系统（几何关系的"榫卯"）

绑定解决"数值联动"，约束解决"几何关系"。二者互补：约束由求解器维持，绑定由计算图传播。

| 约束 | 创建方式 | 求解语义 |
|------|---------|---------|
| 重合 Coincident | 拖点 A 到点 B 上（自动建议）或菜单 | A、B 同坐标（合并或链接） |
| 过点 On-curve | 拖点到线/圆/函数曲线上 | 点被约束在线上，可沿线滑动（参数 = 曲线参数 u，可绑定！） |
| 中点 Midpoint | 菜单 | 点 = 线段中点 |
| 平行 / 垂直 | 选两条线 → 菜单 | 角度关系 |
| 等长 / 等角 | 选两元素 → 菜单 | 数值相等（内部转为绑定） |
| 相切 Tangent | 线 + 圆/曲线 → 菜单 | 距离 = 半径 / 法线共线 |
| 水平 / 竖直 | 菜单 | 角度锁定 |

**实现（已落地）**：**自研 Gauss-Newton 数值求解**（`app/src/constraints.js`）—— 残差函数 + 数值雅可比 + Marquardt 阻尼 + 线搜索 + 步长上限；只求解"自由参数"（被绑定的参数不参与，**正在被拖动的参数被钉住**），并有分档求解（先用小对象满足，不够才动用大对象）。优先级：硬约束（用户创建）> 软约束（拖动目标）。约束在画布上以极小徽章呈现（满足=紫、未满足=橙），属性面板可逐条删除；删除图形时约束级联清理。

**关键设计**：「过点于曲线」+「观察器」是微积分演示器的地基——曲线上点 P 的 `x` 可绑定到变量 `a`，于是滑杆驱动 P 在曲线上滑动（见 04 文档剧本三）。

## 8. 函数生成器与表达式

右侧面板「ƒx」页：

- **输入框**（常驻顶部）：支持 `y=2x+3`、`2x+3=y`、`x²+y²=25`、`r=2θ`、`x=t, y=sin(t)`；语法高亮 + 即时错误提示（仅样式提示，不打断）。
- **智能滑杆建议**：表达式中未定义的字母（除 x/y/t/θ/r 外）→ 下方出现 chips：`为 a 创建滑杆`，点击即建（Desmos 式）。
- **定义域**：默认全定义域；可输入 `x∈[-2π, 2π]`。
- 生成即实体：进入画布后与普通实体完全同权——可拖（整体平移 = 改截距/相位，系统自动判断反解哪个系数）、可关联、可求导、可被成就引擎识别。
- **方程可视化**：隐函数（圆锥曲线、笛卡尔叶形线…）走 marching squares 渲染；参数方程/极坐标走参数采样。

## 9. 预设库

抽屉式面板（不离开画布），分类陈列，**拖入画布即用**。每个预设 = 一个打包的实体（或实体组+预置绑定），参数表完整暴露。

## 10. 微积分工具组 🧮（"手搓演示器"的弹药库）

不靠专门功能，而是五个小实体 + 已有原语的组合：

| 工具 | 本质 | 暴露参数 |
|------|------|---------|
| 线上点 | 过点约束于函数曲线 | `u`（=x 值，可绑定变量/被观察） |
| 切线 | 一点 + 数值求导生成的直线 | `m`（斜率=导数值，可观察/绑定） |
| 割线 | 两个线上点 + 过两点直线 | `m`（差商） |
| 导函数 | f 的数值导数，作为新函数实体 | 完整函数参数 |
| 积分区域 | 黎曼和可视化（矩形/梯形） | `a, b, n`；派生 `S`、`error` |

**由此用户可纯组合实现**：割线逼近切线（变量 h→0）、导数的几何意义、黎曼和收敛（n→∞）、微积分基本定理（积分区域值 S 绑定到观察器，与原函数增量对照）。完整操作剧本见 [04-交互示例剧本 §3](./04-交互示例剧本.md)。

## 12. 功能边界（一期明确不做）

| 不做 | 原因 |
|------|------|
| 3D 绘图 | 与 2D 草稿纸心智冲突，成本翻倍；P18 之后再议 |
| 符号计算（CAS） | 数值路线足够撑起全部演示场景；CAS 留给集成 mathjs 的有限代数简化 |
| 多人协作 | 单机心流优先；分享链接先行 |
| 课程/题库/批改 | 与"探索玩具"定位互斥（见 01 章 §3） |
| 账号系统（早期） | 本地优先，匿名可玩全程；云同步随 P15 引入 —— **已于 P15 落地**（用户名 + 密码 + 会话 token，`GET/PATCH /api/v1/me`，云端场景表）；未登录仍可玩全程 |
