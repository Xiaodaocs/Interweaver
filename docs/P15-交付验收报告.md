## 四、这一路的失败记录（详见 `docs/P15-附二-实施复盘.md`）

- 走线降交叉：**三次失败**（车道单调 63 / 层内重排 90 / 主干道 67）→ **曲线一次成功**（57 → 20）；根因数据：长边（跨 ≥3 层）贡献 **95%** 的交叉；
- 列间走廊：从 **−1.84px（数学上无路）** 到 **6/6 净空为正**；根因是松弛"排斥常量 + 回拉 8%"⇒ 平衡位移 ≈275px（实测列内偏差 281px）；
- 三条设计冲突（组间散 ⟂ 曲线占比、带内归属 ⟂ 画布高度、枢纽密 ⟂ 层=难度）——都已在文档中给出实测数字与取舍建议；
- 成就判据五条教训：键名写错、参数存放/读取不一致（导致切线 `m`、`func.expr` 全为 NaN）、静默吞异常、**量 ≠ 实体**、构造 API 返回值不检查。
