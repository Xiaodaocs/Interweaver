## 0. 技术选型基线（P1 前确认 → **已落地的实际选型**）

> 下表左列是立项时的原定方案，右列是**仓库里现在真实跑的选型**（两者不同的都已换掉）。
> 一句话概括实际形态：**零第三方运行时依赖的原生 ESM + Canvas2D，无构建步骤，前后端分离，后端用 Node 内置 `node:sqlite`。**

| 层 | 原定 | **实际（已实现）** | 理由 |
|----|------|------------------|------|
| 框架 | React 18 + TypeScript + Vite | **无框架 / 无构建**：原生 ESM 直接跑，页面 = 5 个 `.html` + `src/*.js` | 核心模块（表达式/计算图/实体/状态/相机/序列化）必须能被 **Node 直接 import** 做自动化核验；免装依赖即可 `node server.mjs` 起服务 |
| 画布渲染 | 自研 Canvas2D → P17 评估迁移 WebGL（PixiJS） | **自研 Canvas2D**（`src/render.js`），未迁 WebGL；成就星图是 DOM/SVG 合成 | 一期实体量 Canvas2D 足够且文本/抗锯齿省心；零依赖约束下不引 PixiJS |
| 表达式 | mathjs（解析）+ 自研 AST | **自研分词器 + 递归下降解析器**（`src/expr.js`、`src/graph.js`） | 需要 AST 级静态分析（自由字母、依赖源、环检测路径、可逆性分析），自研比适配 mathjs 更直接 |
| 约束求解 | kiwi.js（Cassowary）起步，几何约束层自研牛顿法 | **全部自研**：`src/constraints.js` 残差 + **Gauss-Newton**（数值雅可比 / Marquardt 阻尼 / 线搜索 / 步长上限）+ 分档求解 | Cassowary 只覆盖线性约束；相切、过点等非线性约束需要几何求解器 |
| 状态 | zustand + 自研响应式计算图 | **自研 `src/state.js`（场景图 + 撤销栈）+ `src/graph.js`（DAG 求值）**，无状态库 | 计算图是核心资产，必须自有 |
| 成就引擎 | 自研模式匹配（数据驱动 YAML 模式库） | **自研子图匹配**（`src/achievements/`），模式库是 **JS 模块**而不是 YAML/JSON —— 判据要能写数值谓词与函数 | 见 03 章；当前 **134 条成就 / 65 个知识点** |
| 存储 | IndexedDB（Dexie）→ P15 云端（Supabase 类 BaaS） | **零依赖三层**：`localStorage`（草稿/进度/设置，按账号命名空间化）+ 本地 `.json` 场景文件 + **自建后端 SQLite**（`node:sqlite`，`docs` 表 + `scenes` 表） | 不引 BaaS；`src/scenes/store.js` 仍保留 IndexedDB 后端并可直接被单测注入 |
| 部署 | 静态站点 + CDN；P15 起加 API | **两个 Node 进程**：前端静态 `app/server.mjs`（5188，无 API）+ 后端 `app/server-api.mjs`（5189，SQLite + 用户系统），可同机可跨源 | 网页端定位；一键脚本 `start.bat` / `npm start`（`app/iw-cli.mjs`） |
| 自动化核验 | （原表未列） | **零依赖 + puppeteer（仅本地核验用）**：`npm run verify` 全链；每个检查**独占端口 + 独占临时库 + 独占临时日志**（`tests/_own-backend.mjs`） | 逻辑模块可被 Node 直接跑，浏览器层用真实 Chromium 断言 |

## 风险前置说明（为什么是这个顺序）

1. **P5/P7（绑定与反解）是全产品最大技术不确定性**（见 07 章），放在最前且各自独立验收——若 P7 反解体验做不顺，产品仍可靠"滑杆正向驱动"成立（剧本一不依赖 P7），**有降级退路**。
2. **成就引擎（P12）依赖实体/约束/绑定全部定型**，因此排第三幕，但模式库文案设计从第一幕即可并行（设计/产品岗）。
3. **知识网（P14）是情感峰值也是渲染峰值**，需要 P17 之前的 WebGL 决策——故 P17 紧随 P14。
4. 每个 ⚠ 高风险里程碑预留 30% buffer；连续两个里程碑超期即触发范围重审（砍预设数量/成就数量，不动核心闭环）。
